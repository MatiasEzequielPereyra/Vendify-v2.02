VENDIFY — FLUJO SCANNER + PIN DE DESCUENTOS
==============================================

INSTALACIÓN
-----------
1. Supabase > SQL Editor
2. Ejecutar completo:
   seguridad_descuentos.sql

3. Reemplazar en Vercel:
   index.html
   app.js
   styles.css
   sw.js

SCANNER / PRODUCTO NUEVO
------------------------
Flujo esperado:

Venta
  ↓
Scanner
  ↓
Código desconocido
  ↓
Registrar producto
  ↓
Formulario Nuevo producto ENCIMA de Venta
  ↓
Guardar
  ↓
Se cierra solo el formulario
  ↓
Producto se agrega al carrito
  ↓
Volvés a la misma venta

Ya no hace falta cerrar Venta manualmente.

DESCUENTOS
----------
Cada Propietario o Administrador configura su PIN personal desde:

Cuenta
→ Configuración
→ General
→ PIN para autorizar descuentos

PIN:
- 4 a 8 números
- se guarda hasheado
- no se guarda en app.js
- no se puede volver a leer
- se puede reemplazar por uno nuevo

Para aplicar descuento:
1. Elegir porcentaje o monto.
2. Ingresar valor.
3. Tocar "Autorizar".
4. Ingresar PIN de cualquier Owner/Admin activo del negocio.
5. Vendify aplica el descuento.

SEGURIDAD
---------
La autorización queda ligada al:
- usuario que vende
- negocio
- sucursal
- subtotal exacto
- tipo de descuento
- valor exacto

Vence a los 3 minutos.

Si cambia el carrito o cambia el descuento, hay que autorizar de nuevo.

El backend también bloquea ventas con descuento sin autorización válida:
no es solamente una protección visual.

RATE LIMIT
----------
5 PIN incorrectos:
→ bloqueo de intentos por 5 minutos.

PRUEBA
------
A) Scanner:
- Abrir Venta.
- Escanear código no existente.
- Registrar producto.
- El formulario debe quedar arriba del POS.
- Guardar.
- Debe volver al POS con el producto en carrito.

B) PIN:
- Entrar como Owner/Admin.
- Configurar PIN, ej. 4826.
- Abrir venta.
- Seleccionar 10%.
- Ingresar 10.
- Sin PIN el total NO debe aplicar el descuento.
- Autorizar con 4826.
- El total debe actualizarse.
- Modificar el carrito.
- El descuento debe quedar pendiente nuevamente.
