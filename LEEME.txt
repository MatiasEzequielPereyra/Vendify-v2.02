MEJORAS
-------
USUARIO
- icono SVG de cuenta en vez de una letra
- desktop: icono + nombre + rol
- móvil: botón de cuenta 44x44
- chevron animado al abrir/cerrar

GESTIÓN
- icono de cuadrícula/apps, más claro para un conjunto de herramientas
- menú dividido visualmente en:
  Operación: Historial / Inventario / Compras
  Administración: Equipo / Diagnóstico
- iconos del mismo tamaño y grosor

SCROLL / POPOVERS
- Usuario y Gestión usan el mismo sistema de posicionamiento
- se anclan al botón con coordenadas del viewport
- abren arriba o abajo según espacio disponible
- al hacer scroll vertical se cierran
- al hacer scroll horizontal del header Gestión se cierra
- en resize/orientación se reposicionan
- abrir Usuario cierra Gestión y viceversa

HEADER
- se elimina visualmente la duplicación Usuario/Rol del segundo nivel
- Sucursal/Caja quedan como contexto
- Vender/Producto/Gestión quedan como acciones
- en desktop las acciones frecuentes se separan a la derecha
- tablet/móvil mantiene scroll horizontal seguro

PRUEBAS
-------
1. Abrir Gestión y scrollear la página: debe cerrarse.
2. Abrir Gestión y mover horizontalmente el header en móvil: debe cerrarse.
3. Abrir Usuario, luego Gestión: Usuario debe cerrarse.
4. Abrir Gestión, luego Usuario: Gestión debe cerrarse.
5. Probar orientación vertical/horizontal del teléfono.
