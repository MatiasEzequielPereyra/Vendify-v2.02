VENDIFY v2.30.1.4 — PERMISOS STOCK + BACK GUARD
=================================================

INSTALACIÓN
-----------
1. Supabase > SQL Editor:
   ejecutar 01_permisos_stock_empleados.sql

2. Vercel:
   reemplazar juntos:
   index.html
   app.js
   styles.css
   sw.js

3. Cerrar sesión y volver a ingresar en los empleados para recargar permisos.

PERMISO NUEVO
-------------
Equipo > Crear/Editar empleado:
"Modificar stock manualmente"

Habilita:
- botones + / -
- ajuste manual con motivo
- conteo físico

NO habilita:
- costos
- editar/eliminar productos
- compras/proveedores
- transferencias
- configuración/equipo

Solo Propietario puede cambiarlo.

USUARIOS EXISTENTES
-------------------
Backfill para no romper la operación actual:
Owner/Admin/Manager -> habilitado
Cashier -> deshabilitado

Después el propietario puede cambiar Admin/Manager/Cashier individualmente.

BACK / GESTO ATRÁS
------------------
El primer gesto Atrás con Vendify activa abre:
"¿Salir de Vendify?"

Cancelar -> permanece en Vendify.
Salir -> navega atrás.

Limitación web/PWA:
Android/iOS no permiten a JavaScript cerrar forzosamente el proceso.
En una PWA abierta sin historial previo puede hacer falta un segundo gesto
Atrás después de confirmar para que el sistema la minimice/cierre.

MEJORA EXTRA
------------
El modal de confirmación ya no muestra "Eliminar" para todas las acciones.
